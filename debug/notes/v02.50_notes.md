## 背景（log73 判决）

- 拓扑 A 极端版确认：环 = 纯 asm 的 pad↔birth-stub 乒乓。v249 行全冻结
  （finish=force=setcur=term=taskclean=0），land=261=pe0(256)+pe1(5)，
  hist 三词跨 4 条恒定，trip 现场 = 出生模板精确复刻
  （fp=0, lr=pad, sp=8137fd88 原始主栈, r6=退出表基址 81edf004）。
- **finish=0 悖论**：蹦床头（trampoline+0x0..+0x1c）到 `bl finish` 是
  无分支直线（7 条指令），255 圈穿越却零 finish → 环在 +0x1c 前离开。
  蹦床上唯一无计数器的分支谓词是 `_current_pending_exception`
  （gp+0x410=812e1d34）守护的 `blne c_o_p_s(uncaught)`；c_o_p_s 的
  epilogue（ldr r6,[ct+0x64]; ldr lr,[r6,#4]; ldr fp,[r6],#8; mov pc,lr）
  与 [r6-4]=pad 逐位吻合。cpe 是最后一个未计数嫌疑者。

## 本版两个改动

### 1. 探针：hist 四元组（cpe 词）

- `vita_v245_hist` 13→17 词；每槽 4 词：r6 / lr / [r6-8] / **cpe**。
- pad 内采 cpe：`movw/movt _current_pending_exception + ldr`，存
  `[r2,#16]`；缩放链 `mov r3,r2; add r3,r3,r3 ×4`（=16×idx 字节）。
- 判读：四槽 cpe 全非零 → 环骑在 cpe!=0 分支上（悖论定谳）；
  全零 → 悖论另有解释，下一层洋葱。

### 2. 刹车：flood 门 BRAKE（首个行为改变）

- trip 时 pad 不再永久 park：
  - `vita_v250_brakes++`（预算 8），镜像到 flood[20]；
  - brakes<8：`tripped=2`（HANDOFF LAST）→ `ldr r0,[r6]; bx r0`
    （[r6]=lightweight_thread_exit，设计好的死亡门）；
  - brakes>=8：`tripped=1` 回落 v02.48 park（wfe 停车）。
- 死亡门路径：lw_exit → Scheduler::terminate（op-2 REM，破 q5
  CYCLE(2)）→ Scheduler::yield()（切活线程）→ 尾部
  current_thread_to_primordial（不返回蹦床）。
- watchdog（vita_watchdog.c）分流：
  - tripped==1：legacy——vita_ring_trap(0)：dump+exit(0x45)；
  - tripped==2：vita_ring_trap(1)：dump-only（**不退出**），然后监控
    CE 泵 30s（120×250ms）——CE 动了 = 自愈（"[WD] BRAKE HEALED:
    CE x -> y"，清 gate 恢复正常轮次）；不动 = exit(0x45)。
- `vita_ring_trap(int brake_mode)`：brake_mode=0 PARK（dump+exit）/
  =1 BRAKE（dump+return）。头部行
  `== RING TRAP v02.50 BRAKE brakes=N ==`。

## 四种结局判读

| 结局 | 日志特征 | 含义 |
|------|----------|------|
| 自愈 | BRAKE 头 + wd "BRAKE HEALED: CE x -> y" + 进程活着 | 死亡门走通，q5 破，VM 恢复——**问题闭环** |
| 刹车未愈合 | BRAKE 头 + 无 HEALED + exit 0x45 | 死亡门走不通（前提被破坏），30s 兜底杀 |
| 兜底退化 | BRAKE 头 brakes=8 或 PARK 头 | 刹车 8 次后回 v02.48 park |
| 纯取证 | v02.49 式 PARK 头（无 BRAKE） | 门未触发（新 freeze 形态？）看 cpe 词 |

## 风险与回滚

- 首个行为改变版：刹车若破坏 lw_exit 前提（[r6] 非死亡门），bx 到野
  地址会崩溃而非 park——但 flood 门已存场 + watchdog 兜底退出仍在。
- 回滚：`git revert 4df2961` 即回 v02.49 纯取证行为。
- pad 静态地址随重编漂移（v02.49=8109b5f8，v02.50 以 .sym 为准）；
  slide 每轮不同，符号化前先锚点校准。
